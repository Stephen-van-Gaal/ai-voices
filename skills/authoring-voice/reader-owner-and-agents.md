# Reader: the owner and the agents

A spec, a plan, a design record, a definition or a handoff that an agent
executes and the owner approves. One set of sentences, two readers, and the
document has to serve both without being written twice.

- **What they already hold.** The agent holds the full technical vocabulary,
  the repository, and every exact identifier in it. The owner holds what
  `reader-owner.md` says. The narrower vocabulary is the owner's, so gloss to
  it: keep the exact term the agent needs, and put the plain gloss beside it.
- **What they do with the document.** The agent executes it. The owner grants
  or withholds its authority, and returns to it only when something has gone
  wrong. A decision the owner must make goes where they will find it, not
  inside a paragraph the agent will read and the owner will skim.
- **What they can check.** The agent checks a path, a slug or a command by
  resolving or running it. The owner checks intent, clinical correctness, and
  whether the document does what they asked for. A term the owner cannot
  resolve makes the approval a formality, and an identifier the agent cannot
  resolve stops the execution.
- **Time and attention.** The agent reads the whole document every time it
  acts. The owner reads it once at approval. Write for the reading that
  happens once.
- **What costs their trust.** For the agent: ambiguity, a rule with no
  condition, an identifier that resolves nowhere. For the owner: a decision
  hidden in prose, a term used bare, and prose that could not be checked
  before it was approved.
- **Affordances that serve them.** A glossary once three or more terms fall
  outside the owner's vocabulary. A code block for every identifier, path,
  command and query. An action-by-role table where the two readers leave with
  different work. A decision path where the document routes on a condition.
- **Reader test.** Could the owner say what will happen when the agent
  executes this, and could the agent execute it without asking a question the
  owner has already answered?
